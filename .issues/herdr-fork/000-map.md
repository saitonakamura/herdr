## Destination

Every box (both macs, fedora, WSL, windows) runs a herdr built from
`saitonakamura/herdr` and installed from `saitonakamura/homebrew-tap` (unix) or the
fork's release asset (windows). The fork carries the behaviour changes below, and
loom and the dotfiles work with every one of them.

## Notes

- Vocabulary: [`GLOSSARY.md`](../../GLOSSARY.md). Decisions with trade-offs:
  [`docs/adr/`](../../docs/adr/) 0001–0008. Fork rules: `FORK.md` (written by 001).
- **The live runtime.** herdr runs every agent pane, the one building it included.
  Never replace the installed binary, restart a herdr server or run `brew` against
  `herdr` without asking the user. Test builds against the debug `herdr-dev` server:
  `env -u HERDR_SOCKET_PATH -u HERDR_CLIENT_SOCKET_PATH cargo run -- <command>`, or a
  throwaway named session.
- **Break nothing.** loom (`~/dotfiles/.config/herdr/plugins/loom`, tests in
  `tests/run.sh`) and the dotfiles depend on herdr's CLI and API. A change that
  breaks them fixes them in the same change. A dotfiles change follows
  `~/dotfiles/CLAUDE.md` § cross-host reconciliation: docs fixed in the repo, one
  `.issues/herdr-fork/` ticket per box for on-box steps.
- **Upstream.** Fork-only. Never open issues, PRs or discussions on herdrdev/herdr.
  Keep changes small and neutrally named so periodic upstream merges stay cheap.
- **License.** Apache-2.0: keep `LICENSE` and notices in the fork and in release
  assets.
- **Rollout.** A behaviour change reaches the boxes as a new fork release
  (`<upstream>+fork.N`) and a `brew upgrade`; only the first cutover (003) has
  per-box tickets.

## Decisions so far

- 2026-10-15: both theme commits (`fix/active-row-surface`,
  `fix/terminal-theme-surfaces`) dropped; upstream fixed it as `active_row_bg` /
  `selection_bg` (#2794, #2838, #4408). Terminal-theme `surface0`/`surface1` fills
  are a `[theme.custom]` matter, no code.
- 2026-10-15 (grilling with the user, five rounds): fork `master` is the
  long-lived branch, upstream merged in; distribution first with no behaviour
  change; then, in order, read layer + state consistency, Claude hooks +
  `blocked_reason`, done / post-create / tab names, agent identity + Parent +
  messages (loom's runtime half), workspace = effort, sidebar pane. Full list in
  the tickets.
- 2026-10-15: fork `master` = upstream/master + setup commit, origin pruned to `master`, fork rules and upstream merge recipe in `FORK.md` ([001](./001-sync-and-branch.md)).
- 2026-10-16: fork releases are `v<upstream>+fork.N` tags built by `fork-release.yml`; fork builds never self-update; first release `v0.9.5+fork.1` ([002](./002-ci-releases.md)).
- 2026-10-16: dogfood early, side session first ([022](./022-dogfood-side-session.md)); releases are tagged on request, not per merge; at cutover the personal session restarts first, work and default at their next natural restart; 003 waits for the side session to prove out.
- 2026-10-22: the sidebar is `herdr-sidebar`, a Rust program shipped with the fork that reads only herdr's API, with sections per effort, the Parent tree, every pane, scope, a narrow collapsed mode and built-in reply/tell/close; loom's per-agent facts move into herdr as annotations, and each fact has one owner (ADRs 0005–0007). Build order: 035 annotations, 019 host, 030 program, 031 dotfiles; 032 loom stops mirroring; 033 and 034 filed ([018](./018-sidebar-content.md)).
- 2026-10-22: an agent started in another workspace has a Source, not a Parent. herdr bounds Parent to one workspace, and loom keeps Source as an annotation. The started agent reports to its Source and to its effort's root, labelled, and `--handoff` cuts the Source copy. Closing never cascades across efforts (ADR 0008). Build in 039, blocked by 035 ([033](./033-cross-effort-spawn.md)).
- 2026-10-22: a non-agent pane re-runs a command after a restart only when marked (`pane set-restore-command`, or a `layout.apply` command); it is typed into the fresh shell in the saved cwd with the pane's `--env` ([034](./034-restart-pane-commands.md)).
- 2026-10-26: a light/dark flip reaches herdr fine, but herdr forwards `?997` before the new `OSC 10/11` land (stale 0–100 ms, lost in 4 of 6 samples), so Claude and pi keep the pre-flip side. Fix in a follow-up: the client sends the appearance only after kitty's `OSC 11` reply, with a timeout. codex never follows (upstream), pi's stored `light` pins it, and the mac's nudge currently does nothing ([043](./043-light-dark-flip-chain.md)).
- 2026-10-27: herdr types a recipient's whole backlog as one block at the state change that lets it take messages: a line each up to five, under a header, one pointer line past five. All of a block's messages are delivered together when it is queued, and a withdraw either comes before the block or is refused after it ([051](./051-batched-delivery.md)).
- 2026-10-29: sandboxed pi restores across a fork restart (`pi --session <id>` through the work shim, args, profile and cwd intact). Stock 0.9.4 saves and restores the bridge's claim too, so the seven panes lost on 10-26 had no claim when stock saved. The likely gap is that `scripts/herdr-bridge` claims once per session and never again after herdr drops authority. No herdr change ([044](./044-pi-sandbox-restore.md)).
- 2026-11-02: `pane read` keeps OSC 8 links only when asked: `--links` (API `links: true` with `format: ansi`, capability `pane_read_links`), through a vendored libghostty-vt formatter patch; default `--ansi` output is unchanged, and the `links` plugin passes the flag where the capability is advertised ([040](./040-pane-read-osc8.md)).
- 2026-11-02 (user): a configured token that renders nothing is a `config check` warning, not an error, so the fork accepts every config stock herdr does ([041](./041-spaces-repo-token-check.md)).
- 2026-11-02 (user): each pane's settled agent status is saved in the session snapshot and restored after a restart; a cut-off turn (`working`, or `awaiting` with no live wait) comes back `blocked`/`interrupted`, so the user decides whether to continue, and herdr holds messages for it ([053](./053-restore-settled-status.md)).
- 2026-11-03: test teardown reaps every process left in a test server's runtime dir (plugin actions, orphaned handoff imports) on Linux and macOS, through one process table in the shared harness; the example plugin loops are bounded. Plugin actions outliving a real server is 054 ([042](./042-test-plugin-process-leak.md)).
- 2026-11-03: herdr-sidebar pins a session-wide attention section (wanted agents and unread reports: loud, steady, quiet, oldest first, reason under each), marks tree rows the same, dims a loud row after ~10 s of focus without marking it read, and `a` runs `[sidebar.actions] ack`; tools/sidebar only ([052](./052-sidebar-attention-two-axes.md)).
- 2026-11-03 (user): herdr-sidebar's menu becomes a herdr popup with each entry's key (open report, which acks on close; ack; reply; tell; close with an outcome and an ack-and-close offer; scope; loom ui), the top-level `r` `t` `c` `a` `p` keys move into it, and the word is "ack" everywhere; tools/sidebar only ([059](./059-sidebar-popup-menu.md)).
